# 価格取得Worker

e-Stat(政府統計の総合窓口)の小売物価統計を月に1回自動で取得し、食材の「100gあたりの値段」の表を配信します。
アプリはこの表を読んで、仮の値段を公式統計の値段に置き換えます。手作業のデータ更新は要りません。

## いまの状態

- 値段を100gあたりに直す計算は、自動テストで確認済みです(`npm test`)。
- e-Stat との実際の通信は、まだ試せていません。手順6の結果を見て、食材と統計の品目名の対応表(`src/mapping.js`)を合わせる必要があります。

## 設定の手順(GitHubとCloudflareの画面だけでできます)

### 1. e-Stat のアプリケーションIDをもらう(無料)

1. https://www.e-stat.go.jp/ でユーザ登録してログインします。
2. マイページの「API機能(アプリケーションID発行)」で、アプリケーションIDを発行します。
   - 名前は「献立ノート」など、URLは Pages のURLで大丈夫です。
3. 発行された英数字のIDを控えておきます。

### 2. Cloudflare に価格表の置き場所(KV)を作る

1. Cloudflare のダッシュボードで「ストレージとデータベース」→「KV」→「名前空間を作成」。名前は `kondate-prices` にします。
2. できた名前空間の **ID** をコピーします。
3. GitHub のこのリポジトリで `worker/wrangler.toml` を開き、`id = "ここにKVのidを貼る"` の部分を、コピーしたIDに書き換えて保存(コミット)します。

### 3. Worker を作る(GitHub連携)

1. Cloudflare の「Workers & Pages」→「作成」→ Worker を「Gitに接続」で作ります。同じリポジトリを選びます。
2. 設定は次のとおりです。
   - プロジェクト名: `kondate-prices`(`wrangler.toml` の `name` と同じにします)
   - ルートディレクトリ: `worker`
   - ビルド コマンド: 空
   - デプロイ コマンド: `npx wrangler deploy`
3. デプロイが終わると、`https://kondate-prices.(あなたのサブドメイン).workers.dev` ができます。これが Worker のURLです。

### 4. 秘密の値を入れる

Worker の「設定」→「変数とシークレット」で、種類を「シークレット」にして2つ追加し、デプロイし直します。

| 名前 | 値 |
| --- | --- |
| `ESTAT_APP_ID` | 手順1のアプリケーションID |
| `ADMIN_TOKEN` | 管理用の合言葉(自分で決めた長めの文字列) |

### 5. 統計表の品目名を確認する

ブラウザで次を開きます。

`https://(WorkerのURL)/admin/meta?token=(ADMIN_TOKEN)`

統計表の品目名・単位・地域の一覧が出ます。この中身をコピーして私に貼ってくだされば、`src/mapping.js` の対応表を合わせます。

### 6. 値段を取ってくる

ブラウザで次を開きます。

`https://(WorkerのURL)/admin/refresh?token=(ADMIN_TOKEN)`

つづけて `https://(WorkerのURL)/prices.json` を開いて、確認します。

- `prices` に食材の値段が入っていること
- `unmatched`(対応する品目が見つからない食材)と `unresolved`(単位が換算できない品目)が、少なくなっていくこと

空になるまで、手順5の対応表の調整を繰り返します。

### 7. アプリにつなぐ

1. GitHub で `public/config.js` を開き、`pricesUrl: ""` に `https://(WorkerのURL)/prices.json` を入れて保存(コミット)します。
2. Pages が自動で作り直され、アプリの食材の値段が公式統計になります。「家族」タブの「お店の値段」の説明に、出典の文も出ます。
3. `worker/wrangler.toml` の `ALLOW_ORIGIN` を、`"*"` から Pages のURL(例: `"https://xxxx.pages.dev"`)に変えると、他のサイトから読まれなくなります。

以降は、毎月10日の午前3時(日本時間)に自動で更新されます。

## 画面に必ず出す出典の文

- 「このサービスは、政府統計総合窓口(e-Stat)のAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。」(アプリが価格表から読んで表示します)
- 値段の出典: 総務省統計局「小売物価統計調査」。地域は名古屋市です(愛知県で調査している都市)。

## 注意

- 統計の値段は全国共通の規格の平均です。豊川市のスーパーの値段とは差が出ます。アプリの「お店の値段」の設定と、買い物リストでの値段の入力で合わせます。
- 統計の公表は、実際の月から1〜2か月遅れます。
- 統計に載っていない食材(かまぼこ、ケーキなど)は、仮の値段のままです。
