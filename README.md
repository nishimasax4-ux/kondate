# 献立ノート

家族の人数と食費の予算から、1週間の献立・食費・買い物リストを作るスマホ向けのWebアプリです。
サーバーは使わず、入力した内容は各自のスマホの中(ブラウザ)にだけ保存されます。

## フォルダの中身

| 場所 | 内容 |
| --- | --- |
| `public/` | 公開するファイル一式。`index.html` が本体、`manifest.webmanifest` と `sw.js` と `icons/` はホーム画面に追加するための設定 |
| `src/` | 本体の元ファイル。献立を組む処理(`planner.js`)、食品(`foods.json`)、料理(`build_recipes.py` → `recipes.json`)、画面(`app2.template.html`) |
| `tests/` | 献立づくりの自動テスト |
| `worker/` | 食材の値段を公式統計(e-Stat)から自動で集める Cloudflare Worker。あとで使います(`worker/README.md`)。使うときは `public/config.js` にそのURLを入れます |

## Cloudflare Pages に公開する手順

1. GitHub で新しいリポジトリを作り(非公開でも大丈夫です)、このフォルダの中身を `main` ブランチに上げます。
2. Cloudflare のダッシュボードで「Workers & Pages」→「作成」→「Pages」→「Gitに接続」を選び、そのリポジトリを選びます。
3. ビルドの設定は次のとおりです。
   - フレームワーク プリセット: なし(None)
   - ビルド コマンド: 空のまま
   - ビルド出力ディレクトリ: `public`
   - 本番ブランチ: `main`
4. 「保存してデプロイ」を押すと、`https://(プロジェクト名).pages.dev` で開けます。
5. 以後は、`main` にコミットするたびに自動で公開されます。

## スマホのホーム画面に置く

- iPhone: Safari で開き、共有ボタン → 「ホーム画面に追加」
- Android: Chrome で開き、メニュー → 「ホーム画面に追加」または「アプリをインストール」

## 会社の人だけに見せたいとき

このアプリは検索に出ないようにしてあります(`noindex`)。URLを知っている人だけが開けます。
もっと確実にしたいときは、Cloudflare の Zero Trust の「Access」で、このPagesのURLを保護し、
会社のメールアドレスにだけワンタイムコードを送る設定にします。50人までは無料です。

## 内容を直したあとの手順

```
python3 src/build_recipes.py   # 料理や食材を直したときだけ。recipes.json が作り直されます
python3 src/build.py           # public/index.html を作り直す
node tests/test_planner.mjs    # 自動テスト(Node.js が必要)
git add -A && git commit -m "直した内容" && git push
```

手元で見るには `python3 -m http.server 8000 -d public` を実行し、ブラウザで `http://localhost:8000` を開きます。

## 知っておくことは

- 入力した家族の情報や記録は、そのスマホのブラウザの中だけにあります。別のスマホには引き継がれません。ブラウザのサイトデータを消すと、記録も消えます。
- 食材の値段は、いまは仮の値です。値段の自動取得は `worker/` にひな形があり、e-Stat の登録が済んでから使います。
- 食品の成分は文部科学省「日本食品標準成分表(八訂)増補2023年」、1日に必要なエネルギーは厚生労働省「日本人の食事摂取基準(2025年版)」をもとにしています。
- 料理の分量は一般的な家庭の量として決めたものです。栄養と食費はめやすです。
- 会社の外にも広く公開するときは、成分表などの利用条件を確認してください。
